🔦 Beacon

Stay on course. Work with intention.

Beacon is an open-source TypeScript + React Chrome extension built on Manifest V3 for focus sessions, gentle website blocking, Smart YouTube / Reddit modes, and local-first productivity analytics. Guide your attention — don't just gatekeep the web. No account, no cloud, no tracking.

What Beacon does

  • Focus sessions — goal, timer presets, Pomodoro, profile-based site lists
  • Website rules — Blocked (hard stop), Warning (intent check), Allowed (no interruption)
  • Smart modes — keep YouTube tutorials and Reddit subreddits open; warn on feeds & Shorts
  • Analytics — focus ratio, distraction events, daily / weekly / monthly reports
  • Privacy-first — all data stored locally; export JSON or CSV anytime
