Beacon

Stay on course. Work with intention.

An open-source TypeScript + React Chrome extension built on Manifest V3. Empower yourself with focus sessions, gentle website blocking, Smart YouTube / Reddit modes, and local-first productivity analytics. Guide your attention — don't just gatekeep the web.

🧩 Manifest V3 📘 TypeScript ⚛️ React 18 🌊 Tailwind CSS ⚡ Vite + CRXJS 🔒 Local-First

🛡️ Website Rules & Dashboard

Block, warn, or allow sites. Keep YouTube tutorials open while blocking Shorts using Smart Modes.

Core Features

  • Focus Sessions Define a goal, choose a timer preset, use Pomodoro, and apply profile-based site lists.
  • Intelligent Blocking Blocked (hard stop via declarativeNetRequest), Warning (intent check page), Allowed (no interruption).
  • Smart Modes Allow YouTube /watch but warn on feeds & Shorts; allow specific Subreddits but warn on the popular feed.
  • Local Analytics Dashboard tracks focus ratio, distraction events, and daily/weekly/monthly reports.
  • 100% Privacy All your data is stored locally using chrome.storage. Export your JSON or CSV anytime. No tracking.
